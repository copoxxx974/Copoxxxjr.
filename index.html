Esports & Tournaments

Understand competitive gaming, tournament formats, team roles, match preparation, and fair-play standards.

  • Solo, duo, squad, league, and knockout formats
  • Team roles, communication, and practice plans
  • Registration, rules, match results, and sportsmanship
OPEN FULL GUIDE
How to get started:
1. Choose one game and learn its official rules and ranked mode. 2. Practise aim, movement, map knowledge, decision-making, and teamwork in separate sessions. 3. Find teammates with similar goals and agree on communication rules. 4. Read the tournament rules, eligibility requirements, schedule, device restrictions, and reporting process before registering. 5. Review each match and track improvements. Never use cheats, account sharing, or prohibited tools; protect your account and avoid tournaments that ask for suspicious payments or passwords.

Gaming Skills

Build better game sense, reliable mechanics, thoughtful settings, and healthy practice habits.

  • Settings, controls, sensitivity, and ergonomics
  • Review mistakes and measure progress
  • Balanced practice, breaks, and team communication
OPEN FULL GUIDE
Practice method:
Set one measurable goal per session, warm up briefly, practise a single skill, then play real matches and review what happened. Change one setting at a time so you can tell whether it helps. Keep your device updated, use trusted downloads, enable account two-factor authentication where available, and take regular breaks. Competitive improvement comes from consistent practice—not from cheats or unsafe downloads.

Coding & Programming

Learn how instructions become programs and how to solve problems using code.

  • Variables, conditions, loops, functions, and data
  • Start with Python or browser-based HTML/CSS/JavaScript
  • Debug errors and build small projects
OPEN FULL GUIDE
Beginner path:
Start with variables and data types, then conditions, loops, functions, and collections. Write tiny programs such as a calculator, quiz, or score tracker. Read error messages carefully and test one change at a time. For web pages, HTML defines structure, CSS controls appearance, and JavaScript adds behaviour. Save versions of your work, name files clearly, and never publish API keys, passwords, or private data in public repositories.

Web Development

Plan, design, build, test, and publish accessible websites for phones and computers.

  • HTML structure, CSS layouts, and JavaScript interaction
  • Responsive design, accessibility, and performance
  • Version control, hosting, and maintenance
OPEN FULL GUIDE
Build a first website:
1. Sketch the page sections and user journey. 2. Create an index.html file, connect a stylesheet and script, and use semantic HTML. 3. Test narrow and wide screens, keyboard navigation, colour contrast, and broken links. 4. Use Git to track changes and publish through a static host. 5. Check the live page after every deployment. A static site cannot securely handle private accounts or admin permissions without a trusted server-side service.

AI Learning Lab

Use AI tools thoughtfully for learning, brainstorming, coding support, and productivity.

  • Write clear prompts with goal, context, format, and limits
  • Check facts, test code, and compare sources
  • Protect private data and respect content rights
OPEN FULL GUIDE
A reliable prompt framework:
State your goal, provide relevant context, describe the output format, and list constraints. Example: “Explain JavaScript arrays to a beginner, give three examples, then create five practice questions.” Treat AI output as a draft, not guaranteed truth. Verify important facts with reliable sources, run code in a safe test environment, and ask for explanations rather than blindly copying answers. Do not paste passwords, identity documents, private messages, or confidential source code into tools unless you understand their data policies.

Cybersecurity & Safety

Learn defensive security, ethical testing principles, privacy, and how to recognise online threats.

  • Passwords, multi-factor authentication, and phishing
  • Security basics and responsible disclosure
  • Understand cybercrime and protect devices
OPEN FULL GUIDE
Stay safe and learn ethically:
Use a unique password for each important account and enable multi-factor authentication. Check links and sender details before signing in; never share one-time codes. Update your operating system, browser, and apps. Ethical security testing requires explicit permission and a clearly defined scope—practise only in your own lab or authorised training environment. Do not access other people's accounts, steal data, deploy malware, or test real systems without permission. If you discover a weakness, document it safely and report it through the organisation's approved channel.

PRACTICAL LEARNING

Turn curiosity into real skills

Small projects help you learn more deeply than simply reading. Keep each project safe, achievable, and easy to review.

🧠 How to learn any new tool

Define one clear goal and learn the essential vocabulary.
Follow a trusted beginner tutorial and reproduce the example.
Change one thing, test the result, and write down what happened.
Build a small original project and explain how it works.
Review errors, verify claims, and keep improving gradually.

⚙️ Project ideas for beginners

Gaming: create a practice tracker or match-review checklist.
Coding: make a quiz, calculator, or simple text adventure.
Web: build a responsive personal learning page.
AI: compare prompt styles and fact-check the answers.
Cyber safety: create a personal account-security checklist.

Is this a tournament platform?

Can I use it on a phone?

Yes. The layout adapts to phones, tablets, and desktop screens, with reduced-motion support for accessibility.

Can the admin panel be secure?
