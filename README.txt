COPOXXX FUTURE WEBSITE — SOURCE FILES

Files:
- index.html: complete responsive website, CSS, JavaScript, embedded CX logo, intro animation, guides, search, and demo customization panel.

IMPORTANT:
This is a static educational website. The demo customization panel is not secure authentication and only changes content in the current browser. Do not store real secrets or use it for private admin access. A production admin panel needs a backend, server-side authentication, authorization, and persistent storage.

PUBLISH WITH GITHUB PAGES:
1. Extract this ZIP.
2. Open your GitHub repository (for example, copoxxx974/Webb).
3. Upload index.html and README.txt to the repository root, replacing the old index.html when prompted.
4. Commit the changes.
5. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root), and Save.
6. Wait for deployment, then open https://copoxxx974.github.io/Webb/

The logo is drawn directly in the HTML/CSS; no separate logo file or assets folder is needed.
